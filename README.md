# Maritas Hud- och Yogaateljé – hemsida

Ny hemsida för Maritas Hud- och Yogaateljé, Målarns Gård, Frillesås. Byggd från kodmallen i Annas sajt (React 19 + TanStack Start, Tailwind 4) och publiceras på Netlify.

- Innehåll: `src/content/site.ts`
- Grafisk profil: `src/styles.css`
- Arbetsregler: `AGENTS.md`

```bash
bun install
bun run dev     # lokal utveckling
bun run test    # tester
bun run build   # produktionsbygge
```
